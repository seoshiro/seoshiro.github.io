System reduced motion and Save-Data bypass camera animation. Pixel ratio is capped at 1.5 (1 on Save-Data), with a 1.7-million-pixel buffer budget. Static geometry is merged by material within each exhibit, preserving click ownership. The main scene is approximately 94k triangles and 147 draw calls in the phone view. Construction yields between exhibits, lighting prefiltering is baked offline, and shaders use compileAsync when the browser supports parallel compilation (compile otherwise). No heavy postprocessing, downloaded 3D models or continuous idle loop is used.
