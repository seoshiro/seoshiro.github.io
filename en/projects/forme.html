FORME.

From references
to a direction.

Collect images, compose a moodboard, and carry its colors and typography into a reusable design kit.

Open demoSource code

MY ROLE

I direct the product and visual presentation, set tasks for AI and review the result. FORME connects collecting references with composition and a design kit. Code and checks were prepared with AI; demo collections are not client work.

  • React
  • TypeScript
  • Web Workers
  • IndexedDB

Who it helps

For a creator developing a visual direction: turn scattered references into an editable composition, palette and typography.

01

Starting point

A collection of images, notes, links, and an idea that hasn’t quite come together.

02

What you leave with

An editable moodboard, a PNG composition, design tokens, CSS variables, and a portable .forme project.

03 / Under the surface

Under the surface.

  1. 01

    The library, board and design kit share one document. A reference color receives a semantic role and travels into the export instead of remaining a separate image.

  2. 02

    A fixed 1400 × 1000 board gives the composition a predictable output format. Arbitrary sizes, rotation and an infinite canvas remain outside the current scope.

  3. 03

    Local original images and .forme archives avoid a required account and let you restore a project in another browser. There is no cloud collaboration.

A documented correction

The repository records a 683 × 384 check that found small palette targets. The Layers list provides larger equivalent selection controls. This is a bounded interface check, not evidence of accessibility on every device.

Try a complete workflow

Open the “Quiet Architecture” demo → move a reference and edit a note → assign an accent in the kit → export PNG and .forme → restore the archive in a clean browser.

Practical boundaries
